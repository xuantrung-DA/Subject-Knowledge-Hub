# Working in this repository

Read [HANDOVER.md](HANDOVER.md) first, then inspect the modules relevant to the task.

- Preserve scope/version isolation, durable checkpoints and commit-before-publish.
- Run database/recovery tests in an isolated Compose project.
- Keep paid calls explicitly opted in and within the user's authorized budget.
- Never expose or commit env secrets, session traces, database dumps or user PDFs.
- Follow Ruff/Prettier and run checks appropriate to the change.
- Update HANDOVER.md when architecture, contracts or operations change.
- Preserve historical benchmark artifacts and their measurement limitations.
